How these questions were generated

Visual Predict Pipeline — no audio, no transcription, purely visual:

  1. VL catalogues tutorials (doubao-seed-2.1-turbo) — watches each tutorial video, logs the operation sequence
  2. DS distils visual rules (DeepSeek-V4-Flash) — from 180 operations across 6 tutorials, extracts 53 if-then rules; 33 excluded for preference splits
  3. DS finds decision points — scans 65 shot boundaries for moments where the next step requires tutorial knowledge → 19 cutoffs
  4. VL sees cut point + DS writes question — three-tier answer: core (all tutorials agree), bonus (some teach), ignored (tutorials disagree)
  5. Screening — audit (4 checks) → cross-tutorial consistency → A0 hobbyist filter → VL verify: 11 → 4 questions
Soft scoring: instead of binary right/wrong, answers are graded on a 0–1 scale. Core elements (tool type, action) carry 70% of the score. Bonus elements (technique detail) carry 30%. Details where tutorials disagree (e.g., trimming direction) are ignored entirely.
